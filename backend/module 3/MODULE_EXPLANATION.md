# Module explanation — release 1.1

The prepared foundation handles security, accounts/preferences and the fixed Photon-compatible location service. This add-on supplies reporting and insights: validated submissions, canonical image persistence, immutable reports, transactional owner deletion/restoration, explicit same-category issue links within 150 m, nearby suggestions within 250 m, safe public summaries and scoped aggregates/CSV. Feed groups by issue root and counts distinct non-deleted, non-rejected reporters, placing active issues first. Proximity alone does not link reports. Private reads require the reporter, assigned officer or administrator. Optional interfaces let module 4 add workflow actions without replacing core routes.
